# Doran 개발 개요서

> 기준: 테스트 버전 0.3.2 (2026-10-05) · 제품명 "Doran(도란)"은 가칭 (상표 검색 전)

## 1. 목적

- PC 화면의 브라우저를 AI 가 직접 조작해 업무를 대신하는 프로그램을 만든다. 참고 제품: Aside (Aside Computer, YC 투자).
- 1차 목표: Aside 와 최대한 비슷한 사용 경험의 **개인 업무용 테스트 버전**.
- 핵심 목표: **최소 토큰(크레딧) 소진으로 최고의 작업 효율** — AI 모델을 부문별로 나눠 배정.
- 경쟁력·차별점은 고도화 단계에서 적용한다.

## 2. 사용 범위 (현재)

| 구분 | 내용 |
|---|---|
| 대상 | 최현철 님 개인 업무 (Windows 11 Pro, 26H2) |
| 적합 | 정보 검색·정리, 공고 확인, 로그인 후 조회 |
| 아직 직접 | 제출·결제·신청, 공동인증서·보안 프로그램 사이트, 파일 업로드, CAPTCHA |
| 배포 | 불가 (구독 방식은 개인 전용, 코드 서명 없음) |

## 3. 전체 구성

```
┌──────────────────────── Doran (Electron 44 데스크톱 앱) ────────────────────────┐
│  화면(UI)            : 탭·주소창 · 작업창(대화/작업) · 웹 미리보기 · 설정          │
│  탭 관리자           : 보이는 탭 + 보이지 않는 "주차장 창"(백그라운드·에이전트 탭) │
│  조작기(Driver)      : 요소 번호표 만들기 · 클릭 · 입력 · 스크롤 · 캡처            │
│  작업 엔진 ① API     : Claude(Sonnet 기본/Opus 승격) + Jev(쉬운 클릭) 혼합 루프    │
│  작업 엔진 ② 구독    : 정품 Claude Code 실행 → Doran MCP 도구로 조작, 한도 대기·재개 │
│  MCP 서버(도구 창구) : 127.0.0.1:47830, 토큰 인증 → 외부 Claude Code·Codex 가 사용  │
│  모델 라우터         : 부문별 공급자·모델·effort 배정, 비용 계산                    │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 4. 작업 방식 3가지

| 방식 | 두뇌 | 비용 | 쓰는 곳 |
|---|---|---|---|
| ① API 키 방식 | Claude Sonnet 5.5(기본) → 막히면 Opus 5.5, 쉬운 클릭은 Jev | 사용량만큼 과금 (작업당 원화 표시) | Doran 작업창 |
| ② 구독 엔진 | 사용자 PC 의 정품 Claude Code (sonnet 기본) | 구독 한도 안에서 (5시간·주간) | Doran 작업창 (엔진을 "구독"으로) |
| ③ 외부 에이전트 | 사용자의 Claude Code·Codex (터미널/앱) | 각자의 구독 | Claude Code·Codex 에서 "Doran 브라우저로 …" |

## 5. 비용 절약 장치 (API 방식 기준)

1. **화면 정보 다이어트**: 매 단계 요소 번호표 위주. 페이지 글은 새 페이지일 때 앞부분만, 캡처는 첫 실제 페이지·실패·요청 시·빈 화면에 가까울 때만.
2. **Jev 혼합**: 쉬운 클릭·스크롤은 TypeSafe Jev(입력 100만 토큰당 $0.042, 출력 무료). 신뢰도 0.7 미만이거나 글 입력·완료 판단은 Claude 로.
3. **승격**: 기본 모델이 2번 연속 실패하면 Opus 로 진행 기록을 넘겨 새로 시작.
4. **effort(생각 깊이)** 부문별 지정, **고정 문구 캐시**, **예산 상한**(기본 1건 500원), **제목 짓기 AI 호출 제거**.
5. 15단계 작업 추정: Opus·기존 방식 약 $1.03 → Sonnet·다이어트 약 $0.29 (약 72% 절감, 추정치).

## 6. 기술 스택

- Electron 44.5.1 (Chromium 내장), Node.js. UI 는 순수 HTML/CSS/JS.
- `@modelcontextprotocol/sdk` 1.32 (MCP 서버, Streamable HTTP), `zod` 4.
- 패키징: `@electron/packager` 20.3 (win32 x64). 설치 프로그램 없이 압축 + PowerShell 설치 스크립트.

## 7. 데이터 저장 위치 (사용자 PC)

| 위치 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Programs\Doran\` | 프로그램 (업데이트는 `resources\app.asar` 교체) |
| `%APPDATA%\Doran\doran-config.json` | 설정 (API 키는 Windows DPAPI 로 암호화) |
| `%APPDATA%\Doran\doran-history.json` | 작업 기록 (최근 100건) |
| `%APPDATA%\Doran\claude-work\` | 구독 엔진 작업 폴더, `logs\` 에 Claude Code 원래 출력 (최근 30개) |
| `%APPDATA%\Doran\Partitions\doran-main` | Doran 브라우저 로그인·쿠키 (평소 크롬과 분리) |

## 8. 핵심 결정과 이유

| 결정 | 이유 |
|---|---|
| 브라우저 엔진 개조(Aside 방식) 대신 Electron 독립 앱 | 1인 비프로그래머 유지보수 가능 범위 |
| 화면 캡처 대신 "요소 번호표" 중심 | 토큰 절약 + 정확도 (jev-ultrafast 방식 참고) |
| 구독은 정품 Claude Code·Codex 경유, Doran 은 MCP 도구만 | Anthropic 정책상 외부 앱의 Claude 로그인·구독 토큰 중개 금지 |
| 앱 안 Claude 로그인(Aside 의 OAuth 방식) 미채택 | 위 정책과 충돌 소지, 계정 제재 위험 |
| 코드 서명 보류, 테스트 중 스마트 앱 컨트롤 끔 | 개인 테스트 단계 비용 대비 효과 낮음 (연 30만 원~) |
| 업데이트는 app.asar 만 교체 | 150MB 재설치 대신 17MB, 설정·로그인 유지 |
