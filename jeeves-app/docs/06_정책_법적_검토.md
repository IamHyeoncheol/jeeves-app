# 정책·법적 검토 기록

> 확인일: 2026-10-05. 정책·가격은 바뀔 수 있으므로 판단 전에 원문을 다시 확인할 것.

## 1. Claude 구독(Pro·Max) 사용 규정 — Anthropic
출처: Claude Code Docs "Legal and compliance" (https://code.claude.com/docs/en/legal-and-compliance)
- 구독(OAuth) 인증은 구독자의 **Claude Code 및 Anthropic 자체 앱 일반 사용**을 위한 것.
- 제품·서비스를 만드는 개발자는 **API 키(Console)** 사용. 외부 앱에 Claude 로그인 제공, 구독 자격으로 요청 중개, 자격·세션 토큰 수집·저장·중개 **금지**.
- 단, 최종 사용자가 **수정하지 않은 Claude Code 실행 파일에 본인 구독으로 로그인**하는 것은 막지 않음.
- Pro·Max 사용 한도는 "보통의 개인 사용" 전제. Anthropic 은 사전 통보 없이 제재 가능.
- 제품에 Claude Code 를 넣어 남에게 제공하려면 Commercial Terms 동의, 사용자 각자 인증, 재판매·중개 금지.

**Doran 적용**: 구독은 정품 Claude Code(사용자 본인 로그인) 실행 + Doran 은 MCP 도구만 제공. Doran 은 로그인 정보를 읽지 않음. 개인 사용 전용.

## 2. Aside 구조 분석
출처: Aside Docs (https://docs.aside.com/help/ai.md, https://docs.aside.com/help/developers.md), 디지털마케터 사용 후기
- 구독 연결: ChatGPT Plus/Pro, Claude Pro/Max, GitHub Copilot — **Aside 앱 안에서 OAuth 로그인 창**을 띄움. → 1번 정책 문구와 충돌 소지. 별도 계약 여부는 확인 불가. **Doran 은 미채택.**
- Claude Code·Codex 연동: `aside mcp` 로 **Aside 가 MCP 서버를 열고 코딩 에이전트가 Aside 브라우저를 사용** (반대 방향). → Doran 이 채택한 방식.
- 벤치마크 자료상 GPT-5.5(openai-codex provider) 사용, 무료 월 500크레딧·Pro 월 $20.

## 3. OpenAI Codex
출처: https://learn.chatgpt.com/docs/auth, Codex MCP 설정 해설
- ChatGPT 로그인·API 키 두 방식. 자동화(CI)는 API 키 권장. `~/.codex/auth.json` 은 비밀번호처럼 취급.
- MCP(HTTP) 등록: `config.toml` 의 `[mcp_servers.doran]` 에 `url`, `http_headers`.
- 외부 앱이 ChatGPT 로그인을 대신 받는 것의 허용 범위는 확인 불가 → Doran 은 하지 않음.

## 4. TypeSafe Jev
출처: https://docs.typesafe.ai/api.md, /models.md
- `POST https://api.typesafe.ai/v1/systemone`, `Authorization: Bearer`, 질문 형식 choice/score/noul, 선택지 최대 255.
- 가격: 입력 100만 토큰당 $0.042, 출력 무료. 문맥 64k(상태+질문 32k), 텍스트 전용(이미지 불가).
