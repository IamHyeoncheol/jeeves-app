# Doran 개발·시험·배포 가이드

## 1. 개발 환경 준비
```
# 소스 zip 을 풀고 그 폴더에서
npm install          # electron 44.5.1, @electron/packager 20.3.0, MCP SDK, zod
npm start            # 개발 실행 (electron .)
```
- Linux 작업 환경에서는 `xvfb-run -a` 로 가상 화면을 써서 실행·시험.
- 시험용 설정 폴더 분리: 환경변수 `DORAN_USER_DATA=<폴더>` (사용자 설정을 건드리지 않음).

- 화면 캡처는 `shots/` 에 저장 → 눈으로 확인.

## 3. 패키징
```
npm run pack:win     # dist/Doran-win32-x64/ 생성 (release·tests·shots·dist 제외)
npx @electron/asar list dist/Doran-win32-x64/resources/app.asar | grep -v node_modules   # 내용 확인 필수
```
- 버전 올릴 곳: `package.json`(version, --app-version), `src/ui/index.html`·`app.js` 의 "테스트 버전", `mcp-server.js` 의 McpServer version, `사용설명서.txt`.

## 4. 업데이트 전달 절차
1. `resources/app.asar` + `update.ps1`(SHA256 기대값 갱신, 백업 이름 `app.asar.before-<버전>.bak`) + `업데이트하기.bat`(ASCII, chcp 65001) + `사용설명서.txt`(UTF-8 BOM, CRLF) + 소스 zip.
2. 사용자에게 파일 전송 후 PC 로 기록: `D:\AI_Project\Doran\<버전>-업데이트\`, 소스는 `D:\AI_Project\Doran\Doran-<버전>-source.zip`.
3. 한 파일 30MB 이하(전송 제한). 전체 재설치가 필요하면 28MB 조각 + 합치기 스크립트.

## 5. 함정 모음 (오늘 겪은 문제와 해결)

| 문제 | 원인 | 해결 |
|---|---|---|
| 백그라운드 탭 클릭이 안 먹음 (다른 사이트 이동 후) | 주차장 창을 화면 밖(-20000)에 두면 새 페이지가 입력을 못 받음 | 화면 안 + 투명 + 마우스 통과 + 포커스 불가, `CalculateNativeWinOcclusion` 끔 |
| 완전히 숨긴 창은 캡처·입력 불가 | 그려지지 않음 | 위와 같음 |
| 백그라운드 탭 키 입력 안 됨 | 창 포커스 없음 | 페이지 안에서 값 설정 + input/change 이벤트, Enter 는 form.requestSubmit |
| 빈 탭(URL 없음)에서 관찰이 멈춤 | 문서가 없음 | 에이전트 탭은 about:blank 로 시작, 빈 페이지는 캡처 생략 |
| `<label for>` 가 입력칸과 중복 번호 | 같은 대상 | 입력칸이 보이면 라벨 제외 |
| 새 페이지 직후 캡처 실패 | 첫 화면 미완성 | 4번까지 재시도 |
| "Illegal characters in path" (설치) | 압축 시 한글 파일명 UTF-8 표시 없음 | **모든 zip(설치본·소스)은 Python zipfile 로** 압축(0x800 표시). `zip` 명령 사용 금지. 0.3.1 이전 소스 zip 의 한글 파일명은 Windows 에서 깨져 보일 수 있음 |
| 패키지에 500MB 포함 | release 폴더가 같이 묶임 | `--ignore=^/release` |
| 설치 창 닫으면 Doran 종료 | 검은 창의 자식 프로세스 | `explorer.exe` 로 실행 |
| 시험 중 셸이 갑자기 종료(코드 144) | `pkill -f 패턴`이 자기 명령줄도 매칭 | 포트·PID 로 정확히 종료 |
| Haiku 4.5 에 effort 전송 시 오류 가능 | 미지원 모델 | Claude 5 계열에만 output_config.effort |
| 승격 시 모델 간 thinking 블록 호환 | 서명 검증 | 승격은 진행 기록 요약으로 새 대화 시작 |

## 6. 보안 주의
- API 키는 코드·패키지에 넣지 않는다. 사용자가 설정에서 입력 또는 "키 파일 선택".
- 개발 중 키를 썼다면 작업 환경에서 즉시 삭제(0.2 때 shred 처리함).
- MCP 토큰이 노출되면 설정에서 재발급.
