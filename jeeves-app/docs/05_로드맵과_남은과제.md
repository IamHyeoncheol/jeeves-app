## 2. 알려진 한계
- 💬 질문·📄 요약 모드는 **API 방식만** (크레딧 필요). 구독만 쓸 때는 🤖 작업 모드로 질문.
- iframe 안 요소, 파일 업로드, 새 창 팝업(같은 탭으로 엶), CAPTCHA, 공동인증서·보안 프로그램 사이트 미지원.
- 구글 로그인이 Electron 앱을 막을 수 있음.
- 구독 엔진은 한 번에 작업 1건.
- Anthropic API 크레딧 부족 상태 (2026-10-05 기준) — API 방식 사용 시 충전 필요.
- 코드 서명 없음 → 스마트 앱 컨트롤 꺼야 실행.

## 4. 결정이 필요한 것 (최현철 님)
1. Doran 의 최종 목표: 개인 업무 도구 vs 판매·배포 제품 (구독 방식은 개인 전용)
2. 제품명 확정 여부 (Doran 은 가칭, 상표 미확인)
3. 제품화 시 명의 (법인·개인사업자·개인) → 코드 서명 명의
4. P1 실무 기능 중 우선순위 (맡기고 싶은 업무 목록 5~10개)
