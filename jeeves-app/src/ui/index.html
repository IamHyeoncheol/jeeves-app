1. AI 공급자 (API 키)

키는 이 PC에서 Windows 보호 기능으로 암호화해 저장합니다. 저장된 키는 화면에 ●로만 표시됩니다.

키 파일(txt)에서 한 번에 불러오기
Anthropic·Gemini·TypeSafe 등 키 모양을 알아서 구분합니다. 불러온 뒤 txt 파일은 지우는 것을 권합니다.

대부분의 서비스는 "OpenAI 호환"입니다. 서비스 안내문에 OpenAI 호환(compatible)이라고 적혀 있는지 확인하세요. 주소는 https:// 만 쓸 수 있습니다(내 PC 로컬 모델만 http://127.0.0.1 허용).

요금 유형: 무료로 표시하면 비용을 0원으로 계산하고 추천에서 먼저 고릅니다. 유료는 단가표로 계산합니다. 무료 등급은 입력이 학습에 쓰일 수 있으니(Gemini 무료는 공식 확인) 민감한 자료는 넣지 마세요. 삭제하면 저장된 키도 함께 지워집니다.

2. 부문별 모델 배정

추천: 키가 있는 공급자 중 부문에 필요한 등급을 채우는 가장 싼 모델(무료 우선)을 자동으로 고릅니다. 직접: 공급자와 모델을 직접 고릅니다. 부문마다 [추천|직접]으로 바꿀 수 있습니다. 생각 깊이(effort)는 낮을수록 빠르고 저렴합니다(Claude 5 계열만 적용).

직접 고른 값은 지워지지 않고, 저장하면 추천이 적용됩니다.

5-1. 구독 연결 (Claude Code · Codex)

내 구독(Claude Pro·Max, ChatGPT Plus·Pro)으로 쓰는 방법입니다. Jeeves은 로그인 정보를 전혀 다루지 않고, 지브스가 최상위에서 정품 Claude Code(Codex는 준비 중)를 직접 실행해 일을 시키고, 그 일꾼이 지브스 브라우저 도구를 씁니다. 개인 사용 전용입니다.

추천 엔진
Claude Code 설치 확인 후 표시됩니다.
Claude Code 설치 확인
확인 전
Claude Code 설치·로그인 방법 (처음 한 번)
  1. 시작 메뉴에서 PowerShell을 엽니다.
  2. Anthropic 공식 설치 명령을 붙여 넣고 Enter: irm https://claude.ai/install.ps1 | iex
  3. 설치가 끝나면 claude 를 입력해 실행 → 화면 안내에 따라 본인 Claude 계정으로 로그인(Jeeves이 아닌 Anthropic 공식 화면).
  4. Jeeves으로 돌아와 위의 [확인]을 누릅니다.

설치 명령은 Anthropic 공식 문서 기준입니다. 바뀌었을 수 있으니 code.claude.com 의 설치 안내를 함께 확인하세요.

Jeeves 도구 창구(MCP)
확인 중…
고급: 외부 에이전트(Claude Code·Codex)가 지브스를 직접 부리게 하기 — 권장하지 않음

지브스가 최상위여야 지시·비용·정보 등급 검사·중지가 한곳에서 돌아갑니다. 이 길을 열면 외부 에이전트가 지브스를 거치지 않고 브라우저를 직접 조작해, 위 통제를 우회할 수 있습니다. 기본은 꺼짐이며, 지브스가 직접 실행하는 Claude Code 에는 영향이 없습니다.

내 Claude Code(터미널)에서 Jeeves 쓰기 — PowerShell에 한 번 붙여 넣기 

          
내 Codex(ChatGPT 구독)에서 Jeeves 쓰기 — %USERPROFILE%\.codex\config.toml 끝에 추가 

          
연결 뒤에는 Claude Code·Codex에게 "Jeeves 브라우저로 ○○ 해 줘"라고 하면 됩니다. 위험한 동작은 Jeeves 화면에서 승인을 받습니다. 토큰은 비밀번호처럼 다루세요.

          


        

        

          
5-2. 개발 모드 (Claude Code · Codex · 기타 개발 AI)

          
개발(Dev) 모드는 일의 난이도(L1 간단 ~ L4 매우 어려움)를 규칙으로 판정해, 비용이 낮은 순 → 난이도를 겨우 채우는 약한 엔진 순으로 개발 AI를 고릅니다. 한도·로그인 문제가 생기면 지브스가 다음 엔진으로 넘깁니다. 모두 고른 프로젝트 폴더 안에서만 일하고, 개인 사용 전제입니다.
