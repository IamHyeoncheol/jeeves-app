Doran(도란, 가칭) 테스트 버전 0.3.2 — 사용 설명서
=====================================================

Doran은 AI 에이전트가 들어 있는 독립 브라우저입니다.
웹페이지를 보면서 질문하거나, 브라우저 조작(검색·클릭·입력·정리)을 AI에게 맡길 수 있습니다.
0000. 0.3.2 에서 달라진 점 (크기 조절)
-----------------------------------------------------
· 작업창과 웹 화면 사이의 세로 구분선을 마우스로 끌어 좌우 폭을 조절할 수 있습니다.
  - 작업 화면 중심일 때: 오른쪽 미리보기 폭이 바뀌고, 미리보기 화면도 자동으로 커지거나 작아집니다(선명도도 맞춰 다시 캡처).
  - 웹 크게 보기일 때: 오른쪽 작업창 폭이 바뀌고, 웹 화면이 나머지 공간을 채웁니다.
  - 구분선을 두 번 클릭하면 기본 폭으로 돌아갑니다. 구분선을 클릭한 뒤 ←/→ 키로도 조절됩니다(Shift 를 누르면 크게).
  - 조절한 폭은 저장되어 다음 실행 때도 유지됩니다.

000. 0.3.1 에서 달라진 점 (화면 배치)
-----------------------------------------------------
· 작업 화면 중심: 대화·작업 영역이 가운데 크게, 웹페이지는 오른쪽에 실시간 미리보기(축소 화면)로 나옵니다.
  - 미리보기를 클릭하거나 위쪽 [⤢ 웹 크게 보기]를 누르면 웹 화면이 크게 나오고 직접 조작할 수 있습니다.
  - 다시 [⤡ 작업 화면으로]를 누르면 돌아옵니다. (단축키 Ctrl+J)
  - 마지막으로 쓴 배치가 기억됩니다.
· 작업 카드의 [📷 화면]: 그 작업이 진행 중인 화면을 카드 안에서 원래 비율로 봅니다(1.5초마다 갱신). 클릭하면 크게.
· 오른쪽 "에이전트 탭": 백그라운드에서 일하는 탭들을 작은 화면으로 보여 줍니다. 클릭하면 크게.
· 구독 엔진: Claude Code 가 도구 목록을 불러오는 내부 기능(ToolSearch)을 허용해, 불필요한 차단 경고를 없앴습니다.
· 진단 기록: 구독 엔진 원래 출력을 %APPDATA%\Doran\claude-work\logs 에 최근 30개까지 저장합니다(문제 해결용, PC 안에만).

00. 0.3 에서 달라진 점 (내 구독으로 쓰기)
-----------------------------------------------------
Doran을 Claude Pro·Max 또는 ChatGPT Plus·Pro 구독으로 쓰는 두 가지 방법이 생겼습니다.
(API 크레딧 없이 사용 가능, 대신 구독의 사용 한도 안에서 동작)

[방법 1] Doran 패널에서 구독 엔진(Claude Code)으로 작업
  ① PowerShell 에서 Anthropic 공식 설치 명령 실행:  irm https://claude.ai/install.ps1 | iex
  ② PowerShell 에 claude 입력 → 화면 안내대로 본인 Claude 계정 로그인 (Anthropic 공식 화면)
  ③ Doran 설정 → 5. 구독 연결 → [확인] 으로 설치 확인 → 작업 엔진을 "구독: Claude Code" 로 → 저장
  ④ 🤖 작업 모드에서 지시. 입력창 아래 배지가 "구독" 으로 보이면 구독 엔진입니다.
  · 5시간·주간 사용 한도에 걸리면 작업 카드에 "한도 대기"와 재개 시각이 표시되고, 풀리면 자동으로 이어갑니다.
  · 모델은 sonnet 추천(한도 절약). opus 는 한도를 빨리 씁니다.

[방법 2] 내 Claude Code·Codex 에서 Doran 브라우저를 도구로 쓰기
  · 설정 → 5. 구독 연결의 명령을 [복사] 해서
    - Claude Code: PowerShell 에 붙여 넣기 (한 번만)
    - Codex(ChatGPT 구독): %USERPROFILE%\.codex\config.toml 끝에 붙여 넣기
  · 그 다음 Claude Code·Codex 에게 "Doran 브라우저로 ○○ 해 줘" 라고 하면 Doran 의 🔌 탭에서 작업합니다.
  · 이때 Doran 이 켜져 있어야 합니다.

[법적·안전 원칙]
  · Doran 은 Claude·ChatGPT 로그인 정보를 읽거나 저장하지 않습니다. 로그인은 각 회사 공식 화면에서만 합니다.
  · 정품 Claude Code·Codex 를 수정 없이 그대로 쓰고, Doran 은 브라우저 도구만 제공합니다.
  · 개인 사용 전용입니다. Doran 을 남에게 판매·배포할 때는 이 기능 대신 API 키 방식을 써야 합니다.
  · 외부 에이전트가 하는 결제·전송·제출·삭제 같은 동작도 Doran 화면에서 승인을 받고, 비밀번호 칸 입력은 막힙니다.
  · 도구 창구(MCP)는 이 PC 안에서만 열리고 토큰이 있어야 접속됩니다. 토큰은 비밀번호처럼 다루세요.

[고친 문제]
  · 백그라운드 탭에서 다른 사이트로 이동한 뒤 클릭이 전달되지 않던 문제를 고쳤습니다.
  · 크레딧 부족 오류가 "요청 형식 오류"로 잘못 표시되던 것을 고쳤습니다.


0. 0.2 에서 달라진 점 (비용 절약)
-----------------------------------------------------
· 기본 모델: 작업·대화는 Claude Sonnet 5.5(Opus의 절반 가격), 막히면 Opus 5.5로 자동 승격,
  페이지 요약은 Claude Haiku 4.5, 쉬운 클릭 판단은 TypeSafe Jev.
· ⚡ 혼합 작업: TypeSafe 키가 있으면 쉬운 클릭·스크롤은 Jev(거의 0원)가 하고,
  글 입력·막힘·완료 확인은 Claude가 합니다. 작업 카드에 ⚡ 표시가 Jev가 한 행동입니다.
· 화면 정보 다이어트: 매 단계 번호표 위주로 보내고, 페이지 글은 새 페이지일 때 앞부분만,
  화면 캡처는 첫 화면·실패했을 때·AI가 요청할 때만 보냅니다.
· 생각 깊이(effort)를 부문별로 정할 수 있습니다(기본: 중간).
· 비용 표시: 작업 카드 오른쪽 위에 실시간 원화 비용, 끝나면 Claude·Jev 호출 수가 나옵니다.
· 예산 상한: 작업 1건이 500원(설정에서 변경)을 넘으면 계속할지 물어봅니다.
· 작업 제목 짓기에 AI를 쓰지 않습니다(0원).
· 설정 → "키 파일 선택": api_key.txt 같은 파일에서 여러 키를 한 번에 불러옵니다.
  불러온 뒤 txt 파일은 지우는 것을 권합니다.
· 0.1에서 저장한 API 키는 그대로 유지되고, 모델 배정은 0.2 기본값으로 바뀝니다.


1. 실행 방법
-----------------------------------------------------
① 압축을 원하는 폴더에 풉니다. (예: 문서\Doran)
② 폴더 안의 Doran.exe 를 더블클릭합니다.
③ "Windows의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행] 을 누릅니다.
   (테스트 버전이라 전자서명이 없어서 뜨는 경고입니다. 정식 배포 때 서명 예정)
④ 자주 쓰려면 Doran.exe 를 마우스 오른쪽 클릭 → [바탕 화면에 바로 가기 만들기]

※ 설치 과정이 없는 "포터블" 방식입니다. 폴더를 지우면 프로그램도 지워집니다.
※ 설정·로그인 정보·작업 기록은 %APPDATA%\Doran 폴더에 저장됩니다.


2. 처음 한 번만: API 키 넣기
-----------------------------------------------------
① 처음 실행하면 설정 창이 자동으로 열립니다. (나중에는 오른쪽 위 ⚙ 버튼)
② "Anthropic (Claude)" 줄에 API 키(sk-ant-로 시작)를 붙여 넣습니다.
③ [저장] → "작업 (브라우저 조작)" 줄의 [연결 테스트] 를 눌러 ✅ 가 나오면 준비 끝.

· 키는 Windows 보호 기능(DPAPI)으로 암호화해 이 PC에만 저장됩니다.
· 기본 배정은 위 "0. 달라진 점"을 참고하세요.
· 부문별로 다른 모델을 쓰려면 "2. 부문별 모델 배정"에서 공급자와 모델 이름을 바꿉니다.
  예) 요약·정리 → OpenRouter + google/gemini-2.5-flash (OpenRouter 키 필요)
      대화 → Ollama + llama3.1 (내 PC에 Ollama 설치 시, 키 불필요·무료)


3. 사용법
-----------------------------------------------------
오른쪽 패널 아래에서 모드를 고릅니다.

[💬 질문]  지금 보는 페이지에 대해 묻거나 일반 질문
  · "현재 페이지 내용 포함"을 켜면 보고 있는 페이지 글을 AI가 함께 읽습니다.
  · 📄 이 페이지 요약 버튼으로 바로 요약할 수 있습니다.

[🤖 작업]  브라우저 조작을 맡기기
  · 할 일을 구체적으로 적습니다. (어디서, 무엇을, 결과를 어떤 형태로)
    예) 구글에서 "전기안전관리법 시행규칙 개정" 최신 뉴스를 검색해서
        상위 3개 기사의 제목, 언론사, 날짜, 핵심 내용을 정리해 줘
  · "새 백그라운드 탭에서": 🤖 표시 탭에서 따로 일합니다. 내가 다른 탭을 써도 방해받지 않습니다.
  · "지금 보는 탭에서": 현재 화면에서 바로 진행합니다. (로그인된 화면에서 이어서 할 때)
  · 진행 과정이 카드로 실시간 표시됩니다. [탭 보기]로 AI가 일하는 화면을 볼 수 있고,
    [중지]로 언제든 멈출 수 있습니다.

단축키: Ctrl+T 새 탭 · Ctrl+W 탭 닫기 · Ctrl+L 주소창 · Ctrl+J AI 입력창


4. 안전장치 (꼭 읽어 주세요)
-----------------------------------------------------
· 결제·구매·송금·전송·제출·삭제·게시 같은 되돌릴 수 없는 버튼은 누르기 전에 반드시 물어봅니다.
  ([허용] / [거절] / [탭 보고 판단])
· 비밀번호·카드번호·주민번호 칸에는 AI가 입력하지 못하게 막혀 있습니다.
  로그인이 필요하면 AI가 질문으로 요청합니다 → [탭 보기]로 직접 로그인 → "로그인 완료"라고 답하세요.
· 웹페이지 안에 "AI에게 ~하라" 같은 숨은 지시가 있어도 따르지 않도록 지시되어 있습니다.
  다만 100% 막는다고 보장할 수는 없으니, 중요한 계정에서는 설정의 확인 모드를
  "모든 동작"으로 바꿔 쓰는 것을 권합니다.
· Doran의 로그인 상태는 평소 쓰는 크롬과 분리되어 있습니다. (Doran 안에서 로그인한 것만 AI가 씀)


5. 알려진 한계 (테스트 버전)
-----------------------------------------------------
· iframe(페이지 안의 페이지) 속 버튼·입력칸은 아직 조작 못 합니다. (일부 관공서·은행 사이트)
· 파일 업로드, CAPTCHA(로봇 확인), 공동인증서·보안 프로그램 설치가 필요한 사이트는 사람이 직접 해야 합니다.
· 구글 로그인은 "안전하지 않은 브라우저"로 막힐 수 있습니다. (네이버·다음 등은 대체로 가능)
· AI가 "완료"라고 해도 결과는 직접 한 번 확인해 주세요.
· 사용량(토큰)만큼 API 요금이 나갑니다. 설정 화면 맨 아래에서 이번 실행 사용량을 볼 수 있습니다.
  설정 "3. 비용 절약 장치"에서 캡처 전송·예산·작업 방식을 조정할 수 있습니다.


6. 다음 고도화 계획(안)
-----------------------------------------------------
· 실제 업무 목록으로 모델별 성공률·비용 실측 비교 → 기본 배정 확정
· iframe·파일 업로드·팝업 창 지원
· 반복 작업 예약(매일 아침 공고 확인 등), 작업 결과를 문서·엑셀로 저장
· 내 업무 맞춤 기능(회사별 작업 템플릿, 경쟁 차별점)
